## Design Context

### Users
Desktop browser users reviewing local or linked business documents. They need a fast, private, read-only preview without uploading files or learning another document interface.

### Brand Personality
Quiet, trustworthy, precise. The shell should create confidence and then disappear behind the document.

### Aesthetic Direction
Refined utilitarian minimalism in light and dark themes. The empty state may introduce the task, but an open document must own the full viewport. Avoid duplicated browser chrome, generic cards, ornamental gradients, and persistent branding bars.

### Design Principles
- Make the document, not the extension, the visual subject.
- Keep one clear primary action before opening; progressively disclose secondary actions.
- Reuse native controls and the Viewer's existing document chrome.
- Preserve keyboard access, visible focus, readable contrast, and reduced-motion behavior.
- Spend no viewport height on decoration after a document is ready.
